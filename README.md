### 🍅 Tomato — Full Stack Food Delivery Platform

> A complete food delivery web application with seamless ordering, secure payments, and real-time admin controls.

**✨ Key Highlights:**
- 🛍️ Built a full-stack food delivery platform using the **MERN stack** — enabling users to browse menus, manage carts, and place orders with a smooth, intuitive UI
- 🔐 Implemented **JWT-based authentication** with secure sign-up, login, and logout flows — protecting user data and sessions across the platform
- 🏷️ Developed **dynamic food category filtering** so users can instantly narrow down items by cuisine or food type, improving discovery and UX
- 💳 Integrated **Razorpay payment gateway** for seamless, secure, and real-time online transactions with payment status tracking
- 🛠️ Built a full **Admin Dashboard** — allowing administrators to add, update, and delete food items and monitor & update live order statuses in real time
- 📱 Designed a fully **responsive UI** ensuring consistent experience across desktop, tablet, and mobile devices

**🔧 Tech Stack:**
`React.js` `Node.js` `Express.js` `MongoDB` `CSS` `JWT` `Razorpay`

### 🏥 Prescripto — Doctor Appointment Booking System

> A multi-role healthcare platform enabling patients, doctors, and admins to collaborate efficiently for appointment management.

**✨ Key Highlights:**
- 👨‍⚕️ Engineered a **multi-role web application** with distinct, secure dashboards for **Patients**, **Doctors**, and **Administrators** — each with tailored features and access controls
- 🔑 Implemented **role-based authentication** with secure registration, login, and **email-based password recovery** to ensure both security and accessibility
- 📅 Developed an intelligent **appointment booking flow** — patients can search doctors by speciality, view availability, and instantly book confirmed slots
- 💳 Integrated **Razorpay** for frictionless appointment fee payments with real-time confirmation and payment history
- 👩‍💼 Designed a powerful **Admin Panel** to manage doctor profiles (add, edit, remove), monitor all appointments, and control platform-wide operations
- 🩺 Enabled **Doctor Portal** with secure login — allowing doctors to view upcoming appointments, accept/cancel bookings, and manage their daily schedule efficiently
- 📊 Added **earnings dashboard** for doctors to track consultation revenues and appointment analytics

**🔧 Tech Stack:**
`React.js` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `JWT` `Razorpay`

### 🔧 Workeasy — Domestic Service Booking Platform

> A smart platform connecting homeowners with verified local service workers for everyday household needs.

**✨ Key Highlights:**
- 🏠 Built a **service marketplace** connecting users with skilled local professionals for household services like **plumbing, electrical repairs, and appliance servicing** — solving a real everyday problem
- 👤 Designed a **User Panel** with intuitive service browsing, easy appointment scheduling, and a real-time service status tracker — keeping users informed at every step
- 👷 Developed a dedicated **Worker Panel** enabling professionals to manage incoming job requests, toggle their availability, and mark tasks as completed — streamlining worker productivity
- 🛡️ Built a comprehensive **Admin Panel** to approve worker registrations, assign jobs, manage service categories, and oversee platform-wide user and worker data
- 🔐 Implemented **secure login with role-based access control** (RBAC) across three distinct user types — Users, Workers, and Admins — for maximum data security
- 🔔 Integrated a **real-time notification system** with appointment scheduling and live status updates to keep all parties informed throughout the service lifecycle
- 💰 Added **Razorpay payment integration** for secure upfront service booking payments with confirmation receipts

**🔧 Tech Stack:**
`React.js` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `JWT` `Razorpay`
